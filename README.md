# The Security Curves  

📊 **Интерактивная визуализация кривых безопасности** с помощью Streamlit  

## 🚀 О проекте  
Приложение позволяет подобрать оптимальное теоретическое распределение для эмпирических данных и построить визуализацию.  

👉 **Основные функции:**  
- Подбор параметров распределения Гумбеля/Фреше/Пирсона 3 типа
- Определение средней абсолютной ошибки
- Визуализация подобранного распределения и эмпирических данных
- Вывод таблицы со стандартными квантилями
